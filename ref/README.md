# Road Rash (Genesis) reference pack

Research target: **Road Rash** (1991), **Road Rash II** (1992) and **Road Rash 3** (1995), for Sega Genesis / Mega Drive. **Road Rash 3 is the primary implementation reference**. These are motorcycle combat racing games by Electronic Arts; do not confuse them with games titled Road Rush.

## Source policy
Descriptions of the original games are marked **Original**; implementation recommendations are marked **Proposed**. Do not assume an unverified detail is canonical. Prefer original manuals and actual Genesis screenshots over remakes, fan art or other platform versions.

## Scope
Gameplay systems, race states, pseudo-3D presentation, motorcycle combat, opponents, progression, economy, visual language, UI, and production asset checklist. This pack is not a frame-perfect reverse engineering specification; numerical physics, exact input combinations and per-bike statistics require gameplay capture or original manual verification.
