# Vehicle road audio

Original synthesized PCM loops generated by `tools/build_vehicle_audio.py`.
Sedan and truck loops combine combustion harmonics, mechanical pulsation and filtered tire/air noise. They are not field recordings.

`vehicle_audio.gd` positions each source on its vehicle, tracks movement for Doppler, changes pitch and loudness with road speed, attenuates with distance and stops voices outside 100 m. Web playback uses stream mode.
