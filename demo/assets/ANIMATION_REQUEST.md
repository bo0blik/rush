## Prompt

Create a production pixel art sprite animation atlas, genuine transparent background. Reference image 1 is style only, reference image 2 is existing rider identity. Exactly 6 columns by 5 rows, 30 evenly sized cells, no gaps, no captions. All sprites same camera: rear chase view, same red classic IZH motorcycle, rider red helmet white stripe, black leather jacket, blue jeans, brown boots. Crisp premium detailed pixel art matching forest concept, black outlines restrained, chrome exhaust, single rear tire. Tire contact fixed at horizontal center and 94% cell height; rider fits 88% cell height, 65% width. Row 1: six chronological idle frames, both boots down to support stationary motorcycle, subtle breathing and helmet motion. Row 2: six chronological riding loop frames, feet firmly on pegs, natural elbow and torso suspension motion, subtle jacket motion, different rotating rear tread each frame. Row 3: six chronological LEFT TURN transition poses progressing upright through gentle lean to strong lean, torso shifts inside turn, left knee opens slightly, boots remain on pegs. Row 4: same progressive RIGHT TURN, mirror biomechanics. Row 5: six chronological braking transition poses from riding to torso upright elbows braced, red brake lamp increasingly bright, final pose left boot beginning to lower for low-speed stop. Keep exact same motorcycle geometry and anatomy across all 30 frames, no duplicated bikes inside a cell, no perspective changes, no text, no ground shadows, no smoke. Each pose must be coherent and usable for animation. Canvas landscape 1536x1280 if possible.
