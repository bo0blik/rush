## Rider prompt

Use case: stylized-concept. Production game asset for a Godot retro Russian motorcycle racer. Reference image is STYLE AND CHARACTER reference only, not an edit target. Generate ONE transparent PNG sprite animation atlas, landscape 1536x1024, EXACTLY 4 columns by 2 rows of equal 384x512 cells. No grid lines, labels, UI, scenery, ground or cast shadows. Each of the eight cells contains the SAME red IZH classic road motorcycle and SAME rider seen directly from behind in a third-person chase camera, black leather jacket, blue trousers, red-white helmet, twin chrome exhausts, narrow rear wheel, red rear lamp. Crisp consistent chunky pixel art like the player in the reference, dark outlines, flat pixel clusters, no antialiasing. All cells have identical scale and alignment: rear tire ground contact at cell x192 y460, helmet near y100, complete motorcycle/rider inside each cell with generous transparent padding. TOP ROW from left to right: straight riding animation frame A; straight riding frame B (tiny suspension bounce and wheel rotation, same geometry); braking frame A with bright red brake lamp; braking frame B. BOTTOM ROW: leaning left frame A; leaning left frame B; leaning right frame A; leaning right frame B. Left/right rider and motorcycle tilt around the SAME rear-wheel contact point by about 18 degrees with matching natural posture. Keep orientation toward the horizon in all frames, never side view or front view. Maintain exact consistent motorcycle proportions across all frames. Fully transparent background, real alpha, no baked checkerboard. No text or logos on plates, no extra people.

## Environment prompt

Use case: stylized-concept. Production environment sprite atlas for a Godot pixel-art motorcycle racing game. Reference image is STYLE reference only. Generate one transparent PNG landscape 1536x1024, EXACTLY 4 columns x 2 rows, eight equal 384x512 cells, no gutters drawn. Each cell contains ONE isolated front-facing roadside object for a 3D billboard. TOP row: tall dark Siberian pine; broad lighter pine; dense blue-green spruce; white-trunk summer birch. BOTTOM row: golden-green birch; second narrow dark pine; low green shrub; gray rocky outcrop with a little grass. Pixel-art look matching the reference forest: crisp chunky clusters, dark edges, limited greens, no photorealism, no smooth gradients or antialiasing. Trees complete from crown to trunk, upright, tree trunk ground contact consistently cell x192 y480, never cropped, generous transparent margins. All backgrounds truly transparent alpha, no ground plane, no shadows, no grass carpet, no checkerboard, no labels, no grid, no UI, no people, no motorcycles. Objects must stay entirely within their equal cells and not touch other objects.
